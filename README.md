# VEESIPP Colombia

Sitio web de VEESIPP Colombia, construido con Next.js, TypeScript y App Router.

## Desarrollo

```bash
npm run dev
```

## Producci&oacute;n

```bash
npm run build
npm run start
```

Las rutas se definen en `app/`. Los componentes y vistas existentes se conservan en `src/`; las vistas est&aacute;n en `src/views/` y son consumidas por las rutas de App Router.
